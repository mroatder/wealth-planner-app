# Wealth Planner

เว็บแอปบันทึกรายรับ-รายจ่ายและวางแผนการเงินส่วนตัว **รองรับการหารค่าใช้จ่ายกับแฟน** ใช้งานบนมือถือได้ (เปิดผ่านเบราว์เซอร์แล้ว "เพิ่มไปยังหน้าจอโฮม")

- **หน้าบ้านและหลังบ้าน:** Nuxt 3 (Vue 3) + Tailwind CSS
- **ฐานข้อมูลและระบบล็อกอิน:** Supabase (PostgreSQL + Row Level Security)
- **เก็บสลิป:** Supabase Storage (ส่วนตัว)
- **อ่านสลิปอัตโนมัติ (OCR):** Google Cloud Vision (หรือ Tesseract.js เป็นตัวสำรอง)
- **โฮสต์:** Vercel
- ใช้ฟรีทั้งหมดสำหรับการใช้งานส่วนตัว (Google Vision ต้องผูกบัญชีเรียกเก็บเงิน แต่ 1,000 รูปแรกต่อเดือนฟรี)

## ฟีเจอร์

| หน้า | ทำอะไรได้ |
|---|---|
| **บันทึก** | บันทึกรายจ่าย / รายรับ / โอนระหว่างกระเป๋า, แนบสลิปให้ระบบอ่านยอดและวันที่, เลือกว่าใครจ่าย, จ่ายส่วนตัวหรือหาร 2, เป็นรายจ่ายประจำหรือไม่ |
| **ประวัติ** | ดูรายการรายเดือน แยก **ของเรา** (หารกับแฟน) กับ **ส่วนตัว**, ค้นหา, แก้ไข, ลบ, ดูสลิป, ติ๊ก PAID เมื่อได้รับ/จ่ายเงินคืน |
| **ยอดค้าง** | ยอดสุทธิที่ค้างกับแฟน (ใครต้องจ่ายใคร) พร้อมประวัติทีละรายการ และบันทึกการรับ/จ่ายคืน |
| **กระเป๋า** | หลายบัญชี (เงินสด, ธนาคาร, บัตรเครดิต ฯลฯ) พร้อม Net Worth |
| **งบประมาณ** | ตั้งวงเงินรายหมวดรายเดือน แถบความคืบหน้าเตือนเมื่อใกล้เกิน |
| **เป้าหมาย** | เป้าหมายการออม โอนเงินจากกระเป๋าเข้าเป้าหมาย |
| **วิเคราะห์** | กราฟและข้อสรุป: สัดส่วนหมวด, จังหวะการใช้จ่าย, แนวโน้ม, รายจ่ายที่เกิดซ้ำ, แนะนำงบและเป้าหมายจากข้อมูลจริง |
| **นำเข้าจากชีต** | นำเข้ารายการเก่าจาก Google Sheets / CSV |

## วิธีใช้งานทุกวัน

1. **บันทึกรายจ่าย:** เมนู *บันทึก* → ใส่ยอด → "ค่าอะไร" → หมวดหมู่ → เลือกว่าใครจ่าย และ *ส่วนตัว / หาร 2* → บันทึก
2. **ใช้สลิป:** ในหน้า *บันทึก* กด "ถ่ายรูปสลิป" หรือ "เลือกไฟล์" ระบบจะเติมยอดและวันที่ให้ ตรวจแล้วกดบันทึก (ใช้ภาพแคปหน้าจอสลิปจะอ่านแม่นกว่าถ่ายรูปหน้าจอ)
3. **ถ้าหารกับแฟน:** เลือก *หาร 2* (หรือเลือกว่าแฟนจ่ายก่อน) ระบบนับเฉพาะส่วนของเราเป็นรายจ่าย และจำยอดที่ต้องรับ/จ่ายคืน
4. **เคลียร์ยอดกับแฟน:** ใน *ประวัติ* (ฝั่ง "ของเรา") หรือ *ยอดค้าง* กดปุ่ม **PENDING → PAID** เมื่อเงินถูกโอนคืนแล้ว เงินจะเข้า/ออกกระเป๋าจริง กดย้อนได้
5. **ทบทวนสัปดาห์/เดือน:** *ประวัติ* เลือกเดือน, *วิเคราะห์* ดูภาพรวมและคำแนะนำ
6. **ตั้งงบและเป้าหมาย:** ใน *วิเคราะห์* มี "แนะนำงบประมาณ" และ "เป้าหมายแนะนำ" ที่ตั้งได้ในคลิกเดียว

### นำเข้าข้อมูลเก่าจากชีต
หน้า *นำเข้าจากชีต* รับคอลัมน์ `Date, Categories, Detail, Cost, IsHalf, HalfAmount, Payor, isFixed` วางข้อความที่คัดลอกจากชีต หรือเลือกไฟล์ CSV/TSV แล้วจับคู่หมวดหมู่ ระบบข้ามรายการที่นำเข้าไปแล้ว

## ติดตั้งและรันในเครื่อง

ต้องมี **Node.js 20 ขึ้นไป** และบัญชี **Supabase** (ฟรี)

```bash
git clone https://github.com/<ชื่อคุณ>/wealth-planner-app.git
cd wealth-planner-app
npm install
cp .env.example .env        # Windows: copy .env.example .env
# แก้ .env ใส่ค่าตามตารางด้านล่าง
npm run dev                 # เปิด http://localhost:3000
```

### ตัวแปรสภาพแวดล้อม (`.env`)

| ตัวแปร | ความหมาย |
|---|---|
| `SUPABASE_URL` | Project URL จาก Supabase → Project Settings → API |
| `SUPABASE_KEY` | คีย์ **publishable / anon** (ห้ามใช้คีย์ secret / service-role) |
| `OCR_PROVIDER` | `vision` (แนะนำ) · `auto` (Vision ก่อน ไม่ได้ใช้ Tesseract) · `tesseract` |
| `GOOGLE_SERVICE_ACCOUNT_JSON` | คีย์ Service Account ของ Google แบบ base64 บรรทัดเดียว (จำเป็นเมื่อใช้ `vision`/`auto`) |

สร้าง base64 ของไฟล์คีย์ใน PowerShell:
```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("C:\path\to\key.json"))
```
**ไฟล์ `.env` และไฟล์คีย์ JSON ห้ามขึ้น Git** (`.gitignore` กันไว้แล้ว)

### ตั้งค่าฐานข้อมูล (Supabase)
เปิด *SQL Editor* แล้วรันไฟล์เหล่านี้ตามลำดับ (รันซ้ำได้):

1. `supabase/schema.sql`
2. `supabase/migrations/003_is_shared.sql`
3. `supabase/migrations/004_delete_functions.sql`
4. `supabase/migrations/005_slips_storage.sql`
5. `supabase/migrations/006_settle_items.sql`

จากนั้นรัน `supabase/verify.sql` ทุกบรรทัดต้องเป็น ✅ (ถ้าเป็น ❌ จะบอกว่าต้องรันไฟล์ไหน) ไฟล์ `002a/002b` ใช้เฉพาะฐานข้อมูลที่สร้างจาก schema เวอร์ชันเก่า

ที่ *Authentication → Sign In / Providers → Email* ปิด "Confirm email" ถ้าอยากสมัครแล้วใช้ได้เลย และ **ปิดการสมัครสมาชิกใหม่** เมื่อสร้างบัญชีของคุณเสร็จ

## ปัญหาที่พบบ่อย

- **`unable to verify the first certificate` ตอนรัน dev:** เครือข่ายมีไฟร์วอลล์ตรวจ SSL สคริปต์ `dev` ตั้ง `NODE_TLS_REJECT_UNAUTHORIZED=0` ไว้ให้เฉพาะเครื่องพัฒนา **ห้ามใส่ใน Vercel**
- **ลบ/แก้ไขแล้วขึ้น `403 Access Denied` / `Failed to fetch`:** ไฟร์วอลล์บล็อกคำสั่ง HTTP DELETE/PATCH การลบในแอปจึงเรียกผ่านฟังก์ชันในฐานข้อมูล (migration 004, 006) ถ้าเจอ ให้ตรวจว่ารัน migration ครบด้วย `verify.sql`
- **`ยังไม่ได้รัน migration …`:** รัน SQL ไฟล์ที่ข้อความบอก แล้วรีเฟรชหน้า
- **ขึ้น `#app-manifest` error หลังลบโฟลเดอร์ `.nuxt`:** หยุด `npm run dev` ลบ `.nuxt` แล้วรันใหม่ (อย่ารัน `npm run build` ขณะ dev เปิดอยู่)
- **อ่านสลิปไม่ได้:** กด "ดูข้อความที่ระบบอ่านจากสลิป" ใต้การ์ดแนบสลิป จะเห็นว่าใช้เครื่องอ่านตัวไหนและ error คืออะไร

## ความปลอดภัย

- ทุกตารางเปิด Row Level Security ผู้ใช้เห็นและแก้ได้เฉพาะข้อมูลของตัวเอง
- สลิปเก็บใน bucket ส่วนตัว เปิดดูผ่านลิงก์ชั่วคราวเท่านั้น และอัปโหลดได้เฉพาะโฟลเดอร์ของตัวเอง
- ไม่มีความลับใดอยู่ในโค้ด ทั้งหมดอยู่ใน `.env` / ตัวแปรของ Vercel
- ข้อมูลการเงินเป็นข้อมูลส่วนตัว: **ตั้ง repository เป็น Private**

โปรเจกต์ส่วนตัว ไม่มีใบอนุญาตสำหรับเผยแพร่ซ้ำ
